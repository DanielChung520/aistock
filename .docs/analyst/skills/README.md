# 大師方法論檔（`>前綴` 載入）

本目錄是 aistock「AI 助手」（ow / opencode-web）**`>` 前綴**載入的大師方法論來源。
在 AI 助手輸入 `>蕭明道 2330`，即會把 `蕭明道.md` 全文注入當輪對話，並以其方法論分析。

## 檔案規範

- 一檔一位大師：`.docs/analyst/skills/<大師>.md`（**純散文 Markdown**）。
- 檔名（去 `.md`）即大師代號，例如 `蕭明道.md` → `>蕭明道`。
- 可選 frontmatter（給別名與狀態用）：

  ```markdown
  ---
  name: 蕭明道
  aliases: [簫明道]
  status: draft
  ---
  ```

  - `aliases`：其他可觸發的寫法（含異體字、英文名）。
  - `status`：`draft`（草稿待審）／`reviewed`（已審）。

## 使用方式（在 AI 助手內）

| 輸入 | 行為 |
|---|---|
| `\` | 跳出**大師清單面板**（僅列大師、不與 opencode 的 `/` 指令混用）；↑↓ 選、Enter/點擊後自動填入 `>大師 ` |
| `/` | 出現指令清單；打 `/大師` 只剩大師指令 |
| `/大師-蕭明道 2330` | 等同 `>蕭明道 2330`（原生指令，有下拉選單） |
| `>蕭明道 2330` | 載入方法論並分析 2330 |
| `> 蕭明道`（`>` 後可空白） | 允許空白；全形 `＞` 亦可 |
| `>蕭明道` | 載入方法論，等待後續指示 |
| `>list` 或 `>help` 或 `>` | 列出目前可用的大師清單 |
| `>不存在` | 回報找不到並列出候選 |

## 維護規則

- 新增/修改 `.md` **免重啟 ow**，下一則訊息即生效。
- 內容為**方法論整理**，非本人言論，也**不構成投資建議**；引用請附可佐證來源。
- 建議標 `status: draft`，經審核後改 `reviewed`。
- 只放「方法論／語氣／準則」，不要放可執行指令（降低 prompt-injection 面）。
